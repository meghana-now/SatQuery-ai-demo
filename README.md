## 🌍 Overview

SatQuery AI is an intelligent remote-sensing analysis assistant that allows
users to interact with satellite imagery using natural-language queries.

Instead of manually interpreting complex remote-sensing datasets, users can
ask questions such as:

> "What changes can you identify in this region?"

> "Which areas show signs of urban expansion?"

> "What land-cover classes are visible in this image?"

The system converts the user's query and imagery into an AI-assisted analysis.
